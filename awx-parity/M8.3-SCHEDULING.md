Status: **implementation in progress; manual validation deferred by user direction**. M8.1 and M8.2 implementation checkpoints were handed off with verification outstanding. HA remains parked; no SAML.

## Existing Community capabilities

- Cron and one-time `run_at` schedules, project/template association, task parameters and scheduled task creation.
- Repository-change polling, schedule activate/deactivate/delete API and audit events.
- Scheduler refresh and timezone configuration.

## Scope / acceptance gates

1. Disabled schedules must never be registered or executed, including repository-change schedules.
2. Reject one-time schedules in the past or exactly now; ensure single-fire semantics and safe deactivation.
3. Enforce schedule-to-template/project ownership and RBAC on create/update and manual execution.
4. Define missed-run policy, timezone/DST behavior, concurrent-run policy and task cancellation.
5. Confirm scheduled task parameters, secrets and audit metadata follow the same protections as manual runs.
6. Add deterministic regression tests, integration tests and operator validation instructions.
