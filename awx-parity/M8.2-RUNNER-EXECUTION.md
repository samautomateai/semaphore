# M8.2 — Runner fleet and execution environments

Status: **implementation in progress**. M8.1 implementation was handed off with manual and automated verification deferred by explicit user direction; no tests were reported as passing. HA is parked. Keycloak OIDC only; no SAML.

## Scope and AWX parity acceptance

1. Runner health and eligibility: stale, future-dated, restarted, inactive and capacity-exhausted runners must not receive new tasks. Webhook runner behavior is explicit.
2. Runner pools: project-scoped and global runner selection, labels/tags, deterministic capacity-aware dispatch, and offline recovery.
3. Execution environments: immutable image reference (digest preferred), supported Docker and Kubernetes executors, secure defaults and no silent fallback from a configured remote executor to host-local execution.
4. Lifecycle: queue, start, cancel, timeout, retry, lost runner, cleanup and log persistence with no duplicate task execution.
5. Security: scoped runner credentials, secret redaction, image allowlisting and resource boundaries.
6. Tests: Go unit/integration tests for scheduling and executor selection; Docker/Kubernetes smoke tests and operational rollback.
