# M8.5 — Project backup, restore and portability

Status: **in progress**. HA parked. Keycloak OIDC only; no SAML.

## Existing Community baseline
- Project export and restore APIs, CLI import/export and typed backup serialization.
- Import verification and partial-restore audit metadata.

## Implemented
- `2ba9b6d`, `0118972`: bound restore JSON request bodies to 32 MiB with HTTP 413 on excess, avoiding unbounded memory consumption.

## Acceptance gates
1. Validate archive format and object ownership, references and conflicts before writes.
2. Ensure import is atomic or documents and reliably reports partial recovery.
3. Verify secrets are encrypted/redacted appropriately in backups and audit.
4. Test round-trip import/export for templates, inventories, schedules, roles and runners.
5. Add restore size-boundary tests, malformed payload tests, CLI parity and migration compatibility.
6. Validate access controls, export permissions and audit trails.

## Deferred operator verification
- Run `go test ./api/projects ./services/project ./services/export`.
- Exercise restore at 32 MiB and 32 MiB + 1 byte, malformed JSON and permission failures.
- Test recovery after partial restore and compare exported/imported project resources.

**Not yet accepted:** round-trip integration tests, transactional rollback, secret handling and real deployment validation. Manual verification deferred; do not claim full AWX parity.
